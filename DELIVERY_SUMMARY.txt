================================================================================
ARCHITECTURE: SERVICE LAYER ISOLATION
================================================================================

The key design pattern enables ZERO COMPONENT CHANGES when integrating a
real backend:

    Components
        ↓
    React Hooks (usePrediction, useHistory)
        ↓
    SERVICE LAYER (src/services/predictionApi.ts)  ← MODIFY ONLY THIS
        ↓
    Mock API (development) OR Real FastAPI (production)

CURRENT: Mock responses with ~800ms simulated delay

TO INTEGRATE YOUR BACKEND:
   1. Open src/services/predictionApi.ts
   2. Replace mock with real fetch() call to your FastAPI endpoint
   3. That's it! All components automatically use new backend

See API_INTEGRATION.md for step-by-step instructions with code examples.

================================================================================
API CONTRACT
================================================================================

The service layer exports:

   async function predictUTI(patientData: PatientData): Promise<PredictionResult>

Input (PatientData):
   - age: number
   - gender: 'Male' | 'Female'
   - urinePh: number
   - specificGravity: number
   - leukocyteEsterase: 'Negative' | 'Trace' | '+' | '++' | '+++'
   - nitrite: 'Negative' | 'Positive'
   - protein: 'Negative' | 'Trace' | '+' | '++'
   - glucose: 'Negative' | 'Trace' | '+' | '++'
   - bilirubin: 'Negative' | 'Positive'
   - urobilinogen: 'Normal' | 'Increased' | 'Decreased'
   - wbcCount: number
   - rbcCount: number
   - dysuriaBool: boolean
   - frequencyBool: boolean
   - urgencyBool: boolean
   - flankPainBool: boolean
   - feverBool: boolean

Output (PredictionResult):
   {
     prediction: 'Likely UTI' | 'Unlikely UTI',
     confidence: number (0-100),
     featureImportance: [
       { feature: string, weight: number },
       ...
     ],
     rocCurve: [
       { fpr: number, tpr: number },
       ...
     ]
   }

See API_INTEGRATION.md for complete FastAPI example and expected response format.
